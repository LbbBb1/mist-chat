## 正文

用了大半年 AI，最烦的就是每个月固定扣费——想聊就聊，不想聊也照扣。

后来自己搭了个客户端，把 API Key 填进去就能用，**按实际用量付费，日常聊天一次几分钱**。

用了两个月，说几个真实感受👇

**① 钱是真的省**
会员 20 刀一个月，折人民币 140 多。
我用 API 按量算，一个月十几块，聊得少的时候不到十块。
没有中间商加价，钱直接给模型方。

**② 聊天记录在这台手机上**
没有服务器，没有账号，不用登录。
对话和 Key 都存在本地，删应用就全删了，干净。
换手机之前记得导出备份（应用里有这个按钮）。

**③ 能把我以前的对话搬过来**
DeepSeek 网页版可以导出历史，我做了导入功能。
ZIP 直接选，带图片，几百个会话能一次进来，还有进度条。
以前那些长对话不用重新问一遍了。

**④ 长对话不卡**
默认只渲染最近 30 条，往上滑才展开更早的。
我有个聊了 200 多轮的，滑起来还是顺的。

**⑤ 手机电脑都能用**
安卓装 APK，iPhone 用 Safari 打开加到主屏幕，电脑直接开网页。
三个端数据各自独立，看你习惯用哪个。

是调用模型的凭证，在 DeepSeek 开放平台注册后自己创建，免费。
创建完复制粘贴到应用设置里就行，两分钟的事。

**要钱吗**
软件我免费放出来的，没收过任何人钱。
你不用给我付任何费用，唯一的花销是模型方按用量收的 API 费。

## 私信常用回复

**问：这个安全吗，会不会盗我 Key？**

> 应用是纯前端的，代码开源在 GitHub 上可以自己看。请求从你手机直连 DeepSeek，中间没有我的服务器。Key 只存在你手机本地。

**问：怎么获取 Key？**

> 打开 platform.deepseek.com 注册，进「API Keys」创建一个，复制粘贴到应用设置里。创建免费，用多少扣多少。

**问：为什么应用商店搜不到？**

> 个人维护的版本，没走商店审核（AI 类应用要备案，个人做不了）。装到桌面后和正常 App 一样用，有图标、全屏。

**问：会不会哪天不能用了？**

> 用的是官方公开接口，只要接口不变就能一直用。应用本身也在 GitHub 上开源，就算我不维护了，代码还在。

**问：能帮我装吗？**

> 安卓的话直接装 APK 就行；iPhone 按说明页操作，30 秒搞定，卡住了截图发我。
