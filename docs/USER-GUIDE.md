# 雾语 Mist 使用手册

面向使用者的完整说明。装机步骤见 [安装指引](https://mist-chat.pages.dev/?help=1)。

---

## 一、第一次使用

### 1. 准备 API Key

雾语本身不提供 AI 能力，需要你自己的 DeepSeek API Key。

1. 打开 https://platform.deepseek.com
2. 注册 / 登录（手机号即可，注册免费）
3. 左侧菜单进 **API Keys** → **创建 API Key**
4. 复制生成的 Key（形如 `sk-xxxxxxxx`）

> Key 只显示一次，务必先粘到别处存好。丢了就删掉重建一个。
>
> 账户里需要有余额才能调用。充值入口在同一页面的「充值」按钮。

### 2. 填写到应用

打开雾语 → 会直接弹出设置面板：

```
设置 → 模型与接口 → 输入 API Key → 粘贴 → 保存
```

旁边有「前往官方获取」的链接，可以直接跳过去。

保存后关掉设置，就能开始聊天了。

### 3. 验证是否成功

发一句「你好」。如果几秒内开始逐字输出，说明配置正确。

如果报错，看[第七节](#七常见问题)。

## 二、基本对话

### 发送消息

底部输入框打字，回车或点发送按钮。

手机端长按输入框可以语音输入（识别后自动填入，可在设置里改成直接发送）。

### 三个开关

输入框上方有三个按钮，按需开启：

| 按钮 | 作用 | 什么时候用 |
|---|---|---|
| **深度思考** | 让模型先推理再回答，更准但更慢更贵 | 数学、逻辑、写代码 |
| **智能搜索** | 联网检索后再回答 | 问实时信息、新闻、价格 |
| **生图** | 生成图片 | 需要配图时 |

三个都关 = 普通对话，最快最省。

### 停止与重试

- 生成过程中点「停止」可以中断
- 对回复不满意，点回复下方的重新生成

### 长对话

超过 30 条消息的会话，顶部会出现「展开更早的 N 条消息」。

默认只渲染最近 30 条，是为了让几百轮的会话也不卡。点一下就能往上翻，滚动位置不会跳。

## 三、会话管理

### 新建 / 切换

左上角汉堡按钮打开侧栏：

- **开启新对话** → 开一个新会话
- 点任意会话标题 → 切换过去
- 会话按「今天 / 昨天 / 7 天内 / 30 天内 / 更早」自动分组

### 搜索

侧栏顶部有搜索框，可以搜**对话标题**和**消息内容**。命中消息的会话会标出来，点进去会自动定位到那条消息并展开。

### 重命名 / 删除 / 置顶

会话右侧的 `···` 菜单里：

- 重命名
- 置顶（置顶的排在最前）
- 删除（只删这一个）

## 四、历史对话导入导出

### 从 DeepSeek 网页版导出

1. 打开 https://chat.deepseek.com
2. 左下角头像 → **设置** → **数据管理**
3. 点 **导出全部对话**
4. 等邮件送达，下载 ZIP

导出文件一般在几百 MB 以内，包含全部会话和图片。

### 导入到雾语

**方式一：文件**

```
设置 → 数据管理 → 导入历史对话 → 上传 → 选择 ZIP
```

**方式二：链接**

把 ZIP 传到网盘或对象存储拿到直链，然后：

```
设置 → 数据管理 → 导入历史对话 → 从链接导入 → 粘贴链接 → 下载并导入
```

导入过程会显示百分比进度条。大文件可能需要几分钟，**期间别锁屏、别切后台**。

> ⚠️ **导入是覆盖式的**：会替换本地全部会话和附件。如果当前有重要对话，先导出备份。
>
> 链接导入需要服务端允许跨域访问。华为云 OBS 的预签名链接可以，多数网盘直链不行——那种情况改用文件上传。

### 导出备份

```
设置 → 数据管理 → 导出所有历史对话 → 下载
```

生成的 ZIP 和 DeepSeek 官方导出格式兼容，可以互相导入。

**换手机、清缓存、卸载前，务必先导出。**

## 五、设置详解

### 模型与接口

| 项 | 说明 |
|---|---|
| API Key | 你的 DeepSeek 凭证 |
| 语言模型接口类型 | 默认 DeepSeek 原生接口；选 OpenAI 兼容可接第三方模型服务 |
| API 地址 | 留空用官方地址，接自建/代理服务时填 |
| 模型 | 默认 `deepseek-flash`，可手动输入其他模型名 |
| 系统提示词 | 自定义 AI 的角色和行为。留空使用内置提示 |
| 温度 | 越高越天马行空，越低越稳定。默认 1.0 |

### 通用设置

| 项 | 说明 |
|---|---|
| 主题 | 浅色 / 深色 / 跟随系统 |
| 语言 | 简体中文 / English |
| 朗读音色 | 语音播报用的音色（海星=女声，暗潮=男声） |
| 语音输入识别后自动发送 | 关掉后识别完只填入输入框，可以改完再发 |
| 助手头像 | 开启后每条回复上方显示头像，可自定义图片 |
| 默认折叠思维链 | 深度思考的过程默认收起，点标题展开 |
| 位置信息 | 用于天气、出行类提问的上下文 |
| 每日 Token 用量提醒 | 显示当天消耗，避免超支 |

### 长期记忆

让 AI 记住你的偏好、项目背景等信息。开启后每次对话会带上这些记忆。

可以手动添加、编辑、删除记忆条目，也可以让 AI 自己判断是否值得记。

### 数据管理

| 项 | 说明 |
|---|---|
| 导入历史对话 | 覆盖式导入，支持文件和链接 |
| 导出所有历史对话 | 打包全部会话和图片为 ZIP |
| 删除所有对话 | 清空本地数据，不可恢复 |

## 六、数据与隐私

**全部存在你自己的设备上。**

```
API Key      → 浏览器 localStorage
对话记录      → IndexedDB（浏览器本地数据库）
图片附件      → IndexedDB
```

没有账号、没有登录、没有云同步。请求直接从你的设备发到 DeepSeek，中间没有第三方服务器。

**代价**：

- 换设备不通用，需要导出再导入
- 清理浏览器数据会一起删掉
- 卸载 Android 应用会清空全部数据

所以：**定期导出备份**。

## 七、常见问题

### 提示「API Key 无效」或 401

- Key 复制时带了空格或换行，重新粘贴
- Key 已被删除（在开放平台重新创建一个）
- Key 所属账号没有余额

### 提示「余额不足」或 402

去 https://platform.deepseek.com 充值。DeepSeek 是预付费，余额用完就停。

### 回复很慢 / 一直转圈

- 关掉「深度思考」和「智能搜索」会快很多
- 检查网络，特别是用代理的情况
- 高峰期官方接口本身会慢

### 导入卡住不动

- 大文件需要时间，248 MB 的归档大概 1–3 分钟
- 期间别锁屏
- 一直不动就取消重来，先确认 ZIP 完整

### 提示「文件中的消息分支已损坏」

导入的 ZIP 不是 DeepSeek 官方导出格式，或者文件损坏。重新从网页版导出一份。

### 换手机怎么迁移

```
旧手机：设置 → 数据管理 → 导出所有历史对话 → 保存 ZIP
新手机：装上雾语 → 设置 → 数据管理 → 导入历史对话 → 选 ZIP
API Key 需要重新填一次（导出不包含 Key）
```

### 怎么更新

**安卓版不会自动更新。** 需要更新时：

```
设置 → 通用设置 → 版本与更新 → 检查更新
```

点一下会查询最新版本。有新版本时按提示下载 APK，覆盖安装即可，**对话记录和设置都会保留**。

**iPhone 和网页版**：联网打开就是最新版本，不需要重新安装（网页资源由 Service Worker 自动刷新）。

### 为什么应用商店搜不到

个人维护的独立版本，没走商店审核。装到主屏幕后和正常 App 一样用。

### 支持哪些模型

默认 DeepSeek 系列。也可以切到「OpenAI 兼容」接口，填其他服务商的地址和 Key，比如自建服务。

## 九、费用估算

软件免费，只有 API 调用费。DeepSeek 官方定价（2026 年）：

| 模型 | 输入 | 输出 |
|---|---|---|
| deepseek-flash | 约 ¥0.5 / 百万 token | 约 ¥2 / 百万 token |
| deepseek-pro | 约 ¥4 / 百万 token | 约 ¥16 / 百万 token |

粗算：一次普通对话（500 字往返）用 flash 大约 **几分钱**；写长文、开深度思考会贵一些。

设置里的「每日 Token 用量提醒」可以盯着实际消耗。
