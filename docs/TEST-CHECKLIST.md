# 上机实测清单

安装包：`DeepChat-1.0.4-release.apk`（5.37 MB / versionCode 5 / v1+v2 签名）

```bash
adb install -r DeepChat-1.0.4-release.apk
```

> 首次安装建议先卸载旧版，避免同包名不同签名冲突。卸载会清空本地对话与 Key，换机前先导出。

---

## 一、安装与首次启动

- [ ] 安装成功，图标正常（白底应用图标，不是系统默认机器人）
- [ ] 冷启动无白屏超过 3 秒
- [ ] 首次启动自动弹出设置，停在「模型与接口」
- [ ] 输入 API Key → 保存 → 进入首页
- [ ] 杀进程重开，Key 仍在（不需要重填）

## 二、对话（核心）

- [ ] 发一条普通消息，回复逐字流式输出
- [ ] 打开「深度思考」再发，思考过程可折叠
- [ ] 打开「智能搜索」再发，出现网页引用角标
- [ ] 点「停止生成」，回复中断且保留已生成部分
- [ ] 重新生成、编辑消息、切换分支都能用
- [ ] 长回答（> 3000 字）滚动流畅，不卡顿
- [ ] 代码块高亮、公式（KaTeX）、表格、Mermaid 图渲染正常

## 三、附件与语音

- [ ] 上传图片，回复能识别图片内容
- [ ] 上传 PDF/Office 文件，回复能读取正文
- [ ] 长按说话，语音转文字后自动发送
- [ ] 点朗读，回复能被念出来（音色可在设置切换）

## 四、历史导入（重点）

- [ ] 设置 → 数据管理 → 上传 → 选 DeepSeek 导出的 ZIP
- [ ] 出现「确认导入历史对话？」弹窗
- [ ] 确认后**能看到百分比进度条推进**（1.0.4 起）
- [ ] 完成提示「已导入 N 个对话」，N 与导出文件里的会话数一致
- [ ] 侧栏按「今天 / 昨天 / 7 天内 / 30 天内」分组
- [ ] 打开一个有几十轮的长会话，顶部有「展开更早的 N 条消息」
- [ ] 点展开后视口不跳动，能继续向上翻

**链接导入（1.1.0 新增）**

- [ ] 数据管理页「导入历史对话」右侧有两个按钮：上传 / 从链接导入
- [ ] 点「从链接导入」弹出输入框，粘贴 `https://…zip` 后「下载并导入」可点
- [ ] 下载时按钮文字变成「正在下载 N%」，下方进度条推进
- [ ] 下载完成自动弹出覆盖确认，确认后提示「已导入 N 个对话」
- [ ] 故意填一个不跨域的链接，能看到「下载失败：…」而不是静默失败

> 链接导入走浏览器 `fetch`，**服务端必须允许 CORS**。华为云 OBS 预签名链接默认带 `Access-Control-Allow-Origin: *`，可直接用；自建 NAS / 网盘直链通常不行，改用文件上传。

**大文件提示**：导入期间别锁屏、别切后台。248 MB 的归档预计 1–3 分钟（1.0.4 优化后）。

## 五、导出与备份

- [ ] 设置 → 数据管理 → 下载，得到 `deepseek_data-日期.zip`
- [ ] 用同一份文件重新导入，会话数量一致

## 六、界面与适配

- [ ] 左边缘右滑能拉出侧栏，主内容跟着位移并变圆角
- [ ] 顶部标题不被状态栏 / 刘海遮住（全面屏机型重点看）
- [ ] 输入框弹出键盘后不被遮挡，收起后布局复原
- [ ] 设置弹层在窄屏下左右边距对称，右侧内容不被裁
- [ ] 切换深色模式，配色正常、无闪白
- [ ] 横屏 / 平板（如有）布局可用

## 七、稳定性

- [ ] 连续切 10 个不同会话，不崩、不卡
- [ ] 导入后马上打开长会话，不崩
- [ ] 生成中切后台再回来，回复继续（或至少不崩）
- [ ] 飞行模式下发消息，报错提示清晰，不白屏

---

## 已知边界（不是 bug）

- **Key 明文存本地**：BYOK 设计，卸载即清空。别在共用设备上存长期 Key。
- **iOS 包需自行编译**：Windows 无法出 IPA，工程在 `DeepChat-ios-1.0.4.zip`。
- **自更新不校验签名**：应用内更新从 GitHub Releases 拉包，仅适合自用渠道。
- **导入是覆盖式**：导入会清空当前全部本地对话，操作前先导出备份。
